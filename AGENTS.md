# Project design guidance

For new games or substantial gameplay/UI changes, read [the game design guide](docs/future-game-design-guide.md) once per task. For small fixes, consult only relevant sections when needed; unrelated work does not require it.

- Follow the user's current request over the guide; distinguish explicit preferences from inferred patterns.
- Preserve each game's identity. A preference for one game's art does not automatically apply to the others.
- Review changed flows for clear goals, meaningful choices, readable mobile layouts, privacy, and smooth transitions. Use relevant existing checks and actual screenshots when useful.
- Keep this file short. Store detailed patterns in the guide, and do not paste its checklist into routine replies or require extra approval steps.
